# Benchmark policy

The Elevate GTM node and the Stape GTM MCP server are external benchmarks.

Use them to compare:

- API resource coverage;
- operation naming;
- n8n node packaging patterns;
- MCP tool boundaries;
- pagination and error-handling expectations.

Do not copy implementation code into this project. Do not make this repository a GitHub fork. Keep benchmark repositories as read-only references and implement the NinjaDataBuilder package independently against the official Google Tag Manager API v2 documentation.
